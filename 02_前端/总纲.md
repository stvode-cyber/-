## 与其他模块关系
- 依赖：01_后端（API）、03_桌面端（desktopAPI）
- 被打包到：03_桌面端（electron/resources/frontend/dist/）
- 数据流：用户交互 → Zustand store → API → 后端

## 三端适配
- Web：相对路径 /api/v1，HttpOnly Cookie 鉴权
- Electron：desktopAPI.getBaseURL() + Authorization header
- Capacitor：VITE_API_BASE_URL 环境变量

## 关键约定
- isDesktop() 判断桌面端（window.desktopAPI 存在）
- useToast 全局通知系统（success/error/info）
- ErrorBoundary 兜底
- 路由 lazy import，按页面分 chunk
