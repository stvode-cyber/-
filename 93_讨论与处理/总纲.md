# 93_讨论与处理 总纲

## 模块目的
问题推演与确认的工作区，与正式资料分离。讨论不直接污染正式模块资料。

## 工作流程
```
发现问题
   ↓
进入 93_讨论与处理
   ↓
建立专题文件夹（YYYY-MM-DD-专题名/）
   ↓
推演（推演方案.md）
   ↓
确认（确认回执.md）
   ↓
回写对应模块（更新正式资料）
   ↓
更新 STATUS.md
```

## 规则
1. 讨论内容不直接写入正式模块资料
2. 确认后才回写到对应模块
3. 每个专题独立文件夹，含推演方案+确认回执
4. 推演文档记录：现状盘点/目标方案/待确认问题/执行顺序
