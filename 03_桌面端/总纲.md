# 03_桌面端 总纲

## 模块目的
Electron 桌面应用，主进程管理后端 spawn + 浮窗系统 + 打包分发，提供原生桌面体验（托盘宠物、便签、倒计时浮窗等）。

## 代码位置
[electron/](../electron/) — `main.cjs` / `preload.cjs` / `package.json`

## 打包命令
```bash
cd electron/
npm run dist:win   # 生成 release-v15/绿角犀-Setup-1.0.0.exe + Portable
```

## 关键约束（详见 project_memory.md）
- 所有窗口 sandbox: true
- 严格 CSP via onHeadersReceived
- window.open 拒绝非 http(s) scheme
- 主窗口 close 时销毁所有浮窗（防端口占用）
- before-quit 用 spawnSync 同步杀后端
