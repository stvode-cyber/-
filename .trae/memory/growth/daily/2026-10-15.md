- [17:15] APK 里搜不到 FilesystemPlugin → 不是没打包，是 classes.dex 里用 UTF8 搜 Java 类名找不到 Kotlin 类（Kotlin 类名在 dex 里是 Mangled 格式）→ 实际 classes2.dex 有 137 处 FilesystemPlugin 引用

## 决策
- 选 Filesystem.downloadFile 改下载链路（一步到位，进度条可选）+ capacitor.config.ts 禁 CapacitorHttp 双保险
- IntentInstallerPlugin 注册用 initialPlugins.add() 代替 load() registerPlugin()，更稳
