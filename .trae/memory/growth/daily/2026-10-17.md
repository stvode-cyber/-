### 关键 learn 入 issues.md
- **Vite manualChunks 必须用函数式**（`(id) => { if(id.includes('pdfjs-dist')) return 'pdfjs-vendor' }`）而不是对象式（`'react-vendor': ['react','react-dom']`），因为函数式能匹配 node_modules 内所有子路径
- **React.lazy 静态声明删路由不够**——`const X = lazy(import(...))` 不管路由用不用都会被 Rollup 打包，必须用条件表达式让 lazy 变成 dead code：`const X = BUILD_MODE==='mobile' ? () => null : lazy(import(...))`
- **后端路由文件只注册子路径**是正常设计——/chat/routes.ts 只暴露 /chat/sessions，smoke-all 测 /chat 根返回 404 不算 bug
