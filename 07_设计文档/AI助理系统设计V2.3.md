## 第一章 产品总览与设计目标

### 1.1 项目背景

现代个人与管理者面临信息过载、多角色切换、健康管理缺失、财务规划模糊等挑战。需要一个统一的AI助理，主动整合工作、生活、财务数据，自动提供分析、提醒与决策建议，实现从被动记录到主动服务的升级。

### 1.2 产品目标

- **一站式个人管理中心**：将日程、任务、健康、财务融合于同一助理。
- **主动智能**：基于用户数据自动生成行程建议、风险预警、健康方案和财务规划。
- **角色自适应**：针对执行岗、管理岗、老板等不同职业角色，提供差异化工作辅助。
- **全平台无缝**：手机、电脑、车机、鸿蒙设备无缝切换，数据实时同步。
- **隐私优先**：多密码空间、端侧推理、分层授权、数据溯源。
- **人性化交互**：9种语气模式、简化任务协商、正向转化建议、送心守护。

### 1.3 用户角色

| 角色       | 描述                                           |
| :--------- | :--------------------------------------------- |
| 普通用户   | 使用生活助理、基础工作助理和个人财务管理       |
| 团队管理者 | 额外获得下属工作分析、项目风险提示、考核建议   |
| 企业经营者 | 全局视图，多项目管理、财务健康度分析、战略建议 |
| 系统管理员 | 配置AI规则、数据接入源、隐私策略               |

### 1.4 核心信条

- **数据驱动**：所有建议必有数据依据，可溯源。
- **用户可控**：介入深度、提醒频率、语气风格均由用户自定义。
- **正向引导**：限制型表述转化为成长型建议，拒绝后提供简化替代方案。
- **隐私至上**：敏感数据不出设备，不同密码进入不同空间。

**场景四：紧急传承触发流程**

text



复制



下载

```

    ↓
系统持续监测最后活跃时间
    ↓

    ↓
联系人发起人工审核 → 提交身份信息+提取码
    ↓
双人复核 → 审核通过 → 解锁详细信息(有效期7天)
    ↓
全流程记录不可变审计日志
```

### 7.3 关键计算公式

- **精力评分** = f(睡眠评分×0.4, HRV×0.3, 运动量×0.15, 工作负载×0.15)
- **任务优先级** = 截止紧急度 × 重要系数 × 阻塞依赖数(1+0.2n)
- **财务健康指数** = 月储蓄率×40 + (1-债务收入比)×30 + 应急基金×10
- **建议置信度** = 数据完整性×0.4 + 历史准确率×0.35 + 采纳率×0.25
- **资料可信度** = 来源权威×0.3 + 内容完整×0.2 + 用户认可×0.25 + AI置信度×0.15 + 多方验证×0.1
- **送心触发公式**：超时T≥30分钟且响应=0 → 通知守护者
- **语气适配**：最终输出 = 基础文本 × (板块+时段+等级权重) → 语气模板
