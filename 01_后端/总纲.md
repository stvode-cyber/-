## 开发纪律（从 AGENTS.md 迁移）
1. 自主开发循环：评估 → 选定下一步 → 实现 → 验证 → 记录 → 循环
2. Trust-but-Verify：必须拿出客观证据（命令退出码/测试输出/运行日志），不靠状态描述判定完成
3. 同一错误连续失败 → 停手分析根因，换思路，禁止 sleep 重试循环
4. 进展汇报必须含：基准数字 + 完成度表 + 剩余工作拆解 + 假设与风险
5. 语言中文，命名英文短小；任务跟踪用 TodoWrite
6. 重大进展/关键决策/用户偏好写入 .workbuddy/memory/

## 安全硬约束（详见 [安全约束.md](安全约束.md)）
- JWT HttpOnly Cookie（Web）/ Authorization header（Electron/Capacitor）
- 后端绑 127.0.0.1，禁止 0.0.0.0
- 密码 bcrypt 加盐，至少8位含字母+数字
- 事务防双花（updateMany with where coins >= cost）
- PII 用 sha256+PEPPER 哈希
- 上传 MIME 白名单（排除 HTML/SVG/JS）
- SQL 用 tagged templates，禁 $queryRawUnsafe
