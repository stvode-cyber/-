# 桌面便签 + 动态壁纸 · 集成文档

> 范围：电脑端（Electron）专属功能。便签数据走后端账号绑定（多端同步）；动态壁纸为本地窗口/配置（桌面专属）。

## 1. 数据模型（Prisma）
- `StickyNote`（1:N → User）：`content, color(yellow|pink|blue|green|purple|orange), x, y, w, h, z, pinned`。
- `WallpaperSetting`（1:1 → User，`userId` 唯一）：`enabled, theme(aurora|bubbles|gradient|starfield|pet), speed(0-100), opacity(0-100), showPet`。

## 2. 后端 API
### 便签 `/api/v1/sticky`（需登录）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 列出当前用户全部便签（按 z 升序） |
| POST | `/` | 新建（content/color/x/y/w/h/pinned 可选，z 自动取最大+1） |
| PUT | `/:id` | 局部更新（owner 校验，越权 403） |
| DELETE | `/:id` | 删除（owner 校验，越权 403） |

### 动态壁纸 `/api/v1/wallpaper`（需登录）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 取或自动建默认配置 |
| PUT | `/` | upsert（enabled/theme/speed/opacity/showPet 可选） |

## 3. 前端
- `StickyBoard.tsx`：共享便签画布（拖拽移动 / 缩放 / 换色 / 防抖保存 / 删除 / 新建 / 点击置顶）。`compact` 模式供浮窗。
- `StickyPage.tsx`：完整编辑页 + `?float=1` 浮窗精简模式（透明背景，关闭按钮调 `toggleStickyWindow`）。
- `WallpaperCanvas.tsx`：Canvas2D 动画，5 主题，speed/opacity 生效；`pet` 主题绘制 2D 漫游宠物。
- `WallpaperPage.tsx`：设置面板 + 实时预览 + 桌面开关（`toggleWallpaperWindow`）+ `?float=1` 整屏动画层。
- 入口：`ProfilePage` 在 `isDesktop()` 时显示「桌面工具」区块（桌面便签 / 动态壁纸）。

## 4. Electron（Electron 壳）
- `createStickyWindow()`：380×540 透明无边框 `alwaysOnTop` 浮窗，加载 `#/sticky?float=1`；`ipcMain.handle('sticky:toggleFloat')`。
- `createWallpaperWindow()`：全屏透明无边框 `alwaysOnTop:false` + `skipTaskbar` + `setIgnoreMouseEvents(true)`（鼠标穿透），加载 `#/wallpaper?float=1`；`ipcMain.handle('wallpaper:toggleWindow')`。
- `preload.cjs`：暴露 `desktopAPI.toggleStickyWindow()` / `toggleWallpaperWindow()`。

## 5. 已知限制
- 动态壁纸层为「全屏透明动画 + 鼠标穿透 + 置于底层」，可见于裸桌面、被应用窗口覆盖；未做 Windows WorkerW 注入式"图标之下真·壁纸"（需原生 ffi，后续增强）。
- 桌面浮窗功能尚未在真实 Electron 运行时实测（仅 cjs `--check` + 构建 + 后端冒烟验证）。
