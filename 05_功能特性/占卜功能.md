> 模块路由前缀：`/api/v1/divination`
>
> 鉴权方式：所有接口均需登录，请求头携带 `Authorization: Bearer <token>`（JWT）

## 通用说明

### 统一响应结构

```json
{
  "code": 200,
  "data": { },
  "message": "ok",
  "timestamp": 1786865911,
  "requestId": "req_xxxxxxxx"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | number | 业务状态码，200 为成功 |
| `data` | object / null | 业务数据，失败时为 null |
| `message` | string | 提示信息 |
| `timestamp` | number | 服务器时间戳（秒） |
| `requestId` | string | 请求 ID，用于日志追踪 |

### 通用错误

| HTTP 状态码 | 场景 | message 示例 |
| --- | --- | --- |
| 401 | 未登录 / token 失效 | 未授权 |
| 422 | 参数校验失败 | 请选择星座 / 请输入你的问题（1-200字）/ 请输入正确的出生日期和时辰 |
| 500 | 服务器异常 | 服务器内部错误 |

### POST /iching 八卦算命

模拟三硬币法投掷六次生成卦象（本卦 + 变卦），并由 LLM 结合提问内容解卦。

**占卦算法说明**

- 每爻投掷三枚硬币，每枚正面记 3、反面记 2，三枚合计为 `sum`
- `sum=6` → 老阴（阴爻，变爻）；`sum=7` → 少阳（阳爻）；`sum=8` → 少阴（阴爻）；`sum=9` → 老阳（阳爻，变爻）
- 六爻自下而上构成本卦；存在变爻（老阴/老阳）时，变爻取反得到变卦
- 无变爻时以本卦卦辞断之，`changingHexagram` 为 `null`

**请求示例**

```http
POST /api/v1/divination/iching
Authorization: Bearer <token>
Content-Type: application/json

{
  "question": "最近的事业发展如何？"
}
```

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `question` | string | 是 | 所问之事，1-200 字 |

**响应示例**

```json

  "data": {
    "question": "最近的事业发展如何？",

      { "coins": [2, 3, 3], "sum": 8, "type": "少阴", "value": 0, "changing": false },
```

## 生辰八字

### POST /bazi 八字排盘

根据公历出生日期时间计算四柱八字（年/月/日/时柱）、五行分布、纳音等，并由 LLM 生成七维命理解读。

**排盘算法说明**

- **年柱**：以立春（约 2 月 4 日）为界切换年份；天干地支由 `(年份-4) mod 10/12` 推得
- **月柱**：以节气（惊蛰/清明/立夏等）确定月支，月干按五虎遁起法推算
- **日柱**：基于儒略日号（JDN）精确计算六十甲子序号
- **时柱**：23-1 点为子时、每两小时一个时辰；时干按五鼠遁起法推算
- **五行统计**：天干各计 1，地支本气计 0.5，藏干按主气 1 / 中气 0.5 / 余气 0.3 加权

**请求示例**

```http
POST /api/v1/divination/bazi
Authorization: Bearer <token>
Content-Type: application/json

{
  "year": 1995,
  "month": 6,
  "day": 15,
  "hour": 11,
  "gender": "male"
}
```

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `year` | number | 是 | 公历年份，1900-2100 |
| `month` | number | 是 | 月份，1-12 |
| `day` | number | 是 | 日期，1-31 |
| `hour` | number | 是 | 小时，0-23（23 点算当天子时） |
| `gender` | string | 否 | `male`（默认）或 `female`，影响乾造/坤造称谓 |

## 星座配对

### POST /compatibility 星座配对

选择两个星座，按占星规则计算契合指数，并由 LLM 生成配对解读。

**配对算法说明**

- **元素亲和度**（基础分）：火+风 / 土+水 = 90；同元素 = 80；火+土 / 风+水 = 60；火+水 / 风+土 = 50
- **相位修正**（在基础分上加减）：三合 120° = +10；六合 60° = +8；同星座 = +5；邻座 = -5；对冲 180° = -8；刑 90° = -10；其余 = 0
- 最终得分限定在 40-100
- **等级划分**：≥90 天作之合；75-89 默契十足；60-74 相辅相成；45-59 求同存异；<45 磨合成长

**请求示例**

```http
POST /api/v1/divination/compatibility
Authorization: Bearer <token>
Content-Type: application/json

{
  "sign1": "aries",
  "sign2": "leo"
}
```

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `sign1` | string | 是 | 星座英文 key 或中文名（你的星座） |
| `sign2` | string | 是 | 星座英文 key 或中文名（TA 的星座） |

| `sign1` / `sign2` | object | 两个星座对象（结构同 /zodiac 列表元素） |
| `score` | number | 契合指数 40-100 |
| `level` | string | 等级：天作之合 / 默契十足 / 相辅相成 / 求同存异 / 磨合成长 |
| `elementRelation` | string | 元素关系描述 |
| `aspect.name` | string | 相位名称（如 `三合（拱相位 120°）`） |
| `aspect.desc` | string | 相位含义说明 |
| `interpretation` | object | LLM 配对解读 |

**interpretation 字段说明**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `summary` | string | 一句话概括配对气质 |
| `love` | string | 约 80 字爱情配对分析 |
| `friendship` | string | 约 80 字友情相处分析 |
| `communication` | string | 约 80 字沟通模式与注意事项 |
| `advice` | string | 一句相处建议 |

**降级行为**：LLM 不可用或输出不可解析（如退化文本）时，自动使用规则文案兜底，字段结构完整。

**错误**

| 状态码 | message |
| --- | --- |
| 422 | 请选择两个星座（sign 为空） |
| 422 | 未知的星座（sign 不在十二星座内） |
