# ai-skills/ 总纲 — 游戏助手技能系统

> 本目录是绿角犀游戏 AI 助手的"外挂大脑"，独立于项目文档管理。
> 玩家问啥 → agent 判断归哪个 skill → 跳过去拿知识回答。

---

## 这个模块是干啥的

给绿角犀游戏 AI 助手提供"路由 + 知识包"系统。
覆盖宠物养成、副本战斗、商城交易、公会社交等游戏场景。

---

## 目录结构

```
ai-skills/
├── 总纲.md              ← 本文件（导航 + 最高原则）
├── agents/              ← 调度员 + 全局流程（流程不对改这里）
│   ├── main.agent.md    ← 路由规则：事情归哪个 skill
│   └── rules.global.md  ← 全局铁律：硬约束 + 软建议 + 兜底
├── skills/              ← 各专科技能包（加能力动这里）
│   ├── index.md         ← skill 索引
│   ├── 新手引导/        ← 流程型：新手任务流程
│   │   └── skill.md
│   ├── 宠物图鉴/        ← 知识型：宠物属性/进化/技能
│   │   └── skill.md
│   ├── 副本攻略/        ← 知识型：副本机制/BOSS打法
│   │   └── skill.md
│   ├── 商城交易/        ← 操作型：购买/充值/退款
│   │   └── skill.md
│   └── [新玩法]/        ← 需要时新建文件夹
│       └── skill.md
├── shared/              ← 公共工具箱（不属于任何 skill）
└── changelog.md         ← 改动日记本
```

## 最高原则（不可覆盖）

1. **两组分开**：ai-skills 是 AI 系统的事，01_后端 ~ 09_工具 是项目文档的事
2. **skill 单一职责**：一个 skill 管一个玩法领域，边界清楚不重叠
3. **路由明确**：玩家问啥跳哪个 skill，没歧义，有兜底
4. **skill 控大小**：每个 skill 200-800 字，超了拆分
5. **多重触发不超 3 个**：用主从模式，防串台
6. **改流程改 agents，加玩法加 skill 文件夹**
