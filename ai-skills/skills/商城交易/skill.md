## 这个 skill 是干啥的

触发后调用接口处理商城交易：购买、充值、退款查询。
不负责：宠物属性（路由到"宠物图鉴"）、游戏规则（路由到"新手引导"）。

---

## 可调用的接口

### 接口 1：查商城商品
- URL: GET /api/shop/items
- 参数: type (pet|item|skin)
- 返回: { id, name, price, currency, stock }

### 接口 2：购买商品
- URL: POST /api/shop/buy
- 参数: itemId, quantity
- 返回: { success, cost, balance, items }

### 接口 3：查充值记录
- URL: GET /api/wallet/orders
- 参数: userId
- 返回: { list, total }

### 接口 4：申请退款
- URL: POST /api/wallet/refund
- 参数: orderId, reason
- 返回: { success, amount, status }

---

## 调用逻辑

### 玩家问"商城有啥"
→ 调接口 1，返回商品列表

### 玩家要购买
→ 先调接口 2，校验余额够不够 → 够则执行 → 返回扣款结果

### 玩家问"充值记录"
→ 调接口 3

### 玩家要退款
→ 调接口 4，7 天内可退，超过拒绝

---

## 回答规矩

### 必须遵守
- 购买前确认"确认花费 X 金币购买 Y？"
- 充值加风险提示"理性消费"
- 退款加"7 天内可退，以实际审核为准"
- 涉及金额带单位

### 建议话术
- "这个商品 500 金币，你余额 800，够买"
- "充值请理性消费，量力而行"
- 余额不足 → "还差 X 金币，可以去签到领"

### 禁忌
- 不承诺"100% 退款成功"
- 不透露其他玩家消费记录
- 不诱导充值
