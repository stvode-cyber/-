## 知识内容

### 宠物类型与克制
- 草系 → 克水系，弱火系
- 火系 → 克草系，弱水系
- 水系 → 克火系，弱草系
- 光/暗系：互克，不参与基础三系循环

### 进化机制
- 等级阶段：幼年体(1-9) → 成长体(10-19) → 完全体(20+)
- 消耗：500 金币 + 对应进化石
- 进化后：属性 +30%，解锁新技能槽
- 觉醒进化：4 条件全满 → 额外 +10% 属性

### 互动系统
- 每日互动上限：5 次
- 方式：喂食、抚摸、对话
- 亲密度：0-100，满 100 解锁特殊对话
- 亲密度影响：进化觉醒条件之一

### 技能搭配建议
- 输出型：主攻技能 + 增益 + 必杀
- 坦克型：嘲讽 + 减伤 + 回复
- 辅助型：治疗 + 加速 + 解控

## 回答规矩

### 必须遵守
- 涉及金币消耗提醒"以实际扣款为准"
- 不打包票"肯定能进化成功"，要加"达到条件后"
- 涉及属性数值带单位

### 建议话术
- "进化要满足三个条件：等级、金币、进化石"
- "觉醒进化要多一项亲密度，属性更好"
- 玩家问"哪个强" → 先问"你喜欢输出还是辅助"

### 禁忌
- 不承诺"100% 进化成功"
- 不透露其他玩家的宠物数据
- 不直接说"某系一定最强"
